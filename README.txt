Spark Reality — static website

This folder contains the production-ready static website build.

To publish it on a static host, extract the ZIP and upload the contents of this
folder to the host's public web root. Serve the site over HTTP or HTTPS; opening
index.html directly as a file may prevent scripts from loading.

The contact form opens a prefilled email draft addressed to
yashworkonly16@gmail.com. The visitor must press Send in their email app.
Automatic email delivery is not configured.

The property photographs are illustrative examples, not live listings.
